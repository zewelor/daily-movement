# Catalog curation

- Read [README.md](README.md) before changing the catalog, especially [Synchronize metadata explicitly](README.md#synchronize-metadata-explicitly) before running synchronization. Edit video URLs and mode assignments only in `videos.json`, grouped by the creator's YouTube handle.
- Use the creator's title, description and playlist context to assign `morning`, `day`, or both. Include stretching as well as mobility and general exercise. Morning sessions belong to `morning`; work or desk breaks belong to `day`; general routines suitable for either can use both.
- Prefer follow-along videos with a complete published runtime of at most 10 minutes, including intro and outro. This is editorial guidance. Longer videos can be included when requested; keep them as ordinary entries without ID-specific exceptions or application duration caps.
- Preserve original titles, creator names and runtimes returned by yt-dlp. Do not estimate runtime from a title or manually invent missing metadata. Fetch missing records with `npm run sync:videos`; use `npm run sync:videos -- --refresh` only for an intentional full refresh.
- Keep `video-metadata.json` in Git. After changing the list, synchronize metadata, run `npm run check:videos`, `npm run check:js`, `npm test` and `npm run build`. Run `npm run test:e2e` after frontend, navigation, build-path or playback changes.
- Before reporting a catalog change complete, inspect the diff of `videos.json` and `video-metadata.json` and confirm that `npm run check:videos` passes for the updated list, including every added video. If synchronization fails or yt-dlp is unavailable, report the blocker without manually filling the cache. Report failed or skipped required checks explicitly; do not report completion while a required check remains unverified or failing.
- Treat a playlist import as a one-time selection of explicit video URLs. Flat playlist entries can contain translated titles: use them to select URLs, then populate the cache through full per-video synchronization without a forced language preference. Record the source, selection rule, counts and skipped entries in `docs/`. Metadata refresh must not silently add playlist uploads.
- Edit frontend source in `src/`. Publish generated `dist/`; preserve clean morning/day URLs and relative paths that work below a GitHub Pages repository prefix.
